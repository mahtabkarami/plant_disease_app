# Plant Disease Detection App An AI-powered plant disease classification web application built with Deep Learning and Streamlit. The model analyzes plant leaf images and predicts plant diseases across 38 different classes. This project focuses on practical image classification, model inference, and user-friendly AI deployment for agricultural applications. --- # Features - Plant disease classification using Deep Learning - Upload plant leaf images for prediction - Real-time inference with Streamlit - TensorFlow/Keras-based image classification model - Confidence score prediction - Interactive web application interface - Streamlit deployment support --- # Dataset & Classes The model is trained on a multi-class plant disease dataset containing 38 classes, including: - Healthy plant categories - Multiple plant diseases - Different crop types Examples include: - Tomato diseases - Corn diseases - Apple diseases - Potato diseases - Grape diseases - Pepper diseases --- # Tech Stack ## Machine Learning - Python - TensorFlow / Keras - NumPy - OpenCV - Matplotlib ## Web Application - Streamlit ## Deep Learning Concepts - CNN (Convolutional Neural Networks) - Image Preprocessing - Image Classification - Data Augmentation --- # Project Structure ```bash plant_disease_app/ │ ├── app.py ├── model/ ├── labels.txt ├── requirements.txt ├── images/ ├── LICENSE └── README.md
